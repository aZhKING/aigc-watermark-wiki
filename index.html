综述脉络

水印研究正在从“给单张图片藏比特”走向“给生成过程、模型参数、三维资产和跨视角渲染链路建立可验证来源”。

二维图像水印是方法底座

HiDDeN 和 StegaStamp 奠定了端到端编码器-解码器、可微失真层、物理拍摄鲁棒性等范式。后续方法开始强调局部盗用、几何变换、扩散再生成、对抗攻击和可证明鲁棒性。

AIGC 水印转向生成过程

Stable Signature、Gaussian Shading、LaWa、SEAL、TAG-WM、ClusterMark 等把水印放进扩散潜空间、初始噪声、文本编码器或自回归视觉 token，使检测与归因更贴近生成链路。

3DGS 水印成为新焦点

3DGS 资产有模型文件可复制、渲染视角多、编辑与压缩链路复杂等问题。GuardSplat、3D-GSW、GS-Marker、W2M、BitC-3DGS 正在围绕容量、鲁棒性、可见质量和威胁模型展开竞争。

时间线

从通用深度水印到 NeRF/3DGS 资产保护，研究对象从图片扩展到生成模型和三维场景表示。

3DGS 转换形式技术树

核心问题不是“把 bit 塞进哪个参数”，而是先把无序 Gaussian 集合转成可学习、可对齐、可复用的结构，再把 2D 图像水印、序列建模、图网络、分割和生成式水印迁移进来。

3DGS 无序 splats 结构化 2D / Graph / Seq Watermark

根问题：无序 3DGS 如何变成稳定水印载体？

MarkSplatter 的启发在于：一旦把 3DGS 规则化为 Splatter Image，通用网络就可以一次前向传播完成任意模型、任意消息的嵌入。下面这些分支都是沿着“结构化 3DGS”继续发散。

图像化把 Gaussian 映射为像素/UV/latent tensor，借 2D watermark 与 encoder-decoder。
图结构化用空间邻近、共可见、遮挡和语义边，找稳定 Gaussian 子图。
序列化用八叉树、Morton/Hilbert 编码或 learnable sorting 建 canonical order。
视角一致选择多视角稳定可见、贡献稳定的 Gaussian 作为承载区域。
攻击不变量从压缩、编辑、重训练和 diffusion editing 后仍保留的结构反推水印位置。
